- Basic Arcade Car Controller (Unity)

This controller is a free, beginner-friendly car controller asset for Unity.  
It is designed as a simple and customizable starting point for arcade-style driving games, prototypes, and learning purposes.

This asset does not aim for full vehicle simulation realism.  
Instead, it focuses on clarity, modularity, and ease of understanding.

This controller contains:

- Basic acceleration, braking, and steering
- Simple tire grip / traction logic (customizable)
- Counter-steering support
- Nitro system
- Center of Mass adjustment
- Fake but controllable gearbox system
- Modular code structure


Important! This asset has following dependencies:

- Unity Input System
  You must enable it from: 
  `Edit → Project Settings → Player → Active Input Handling → Input System Package`

- Cinemachine 
  Not required for the controller itself,  
  but necessary for the camera in the DemoScene.

- TextMeshPro is required for UI (included by default in most Unity projects).

Controls:

- WASD / Arrow Keys – Controls
- Space - Handbrake
- Shift / Left Shift – Nitro

Additional Notes:

- This asset uses WheelCollider for simplicity.
- Engine sounds are placeholder examples.
- Vehicle physics are intentionally simplified.

Intended Use:

- Learning vehicle controllers in Unity
- Prototyping arcade-style driving games
- Base system for further customization
- Beginner and intermediate projects
